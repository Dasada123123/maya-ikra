# Майя · Красная икра

Мини-приложение Telegram для @Ikra_mayya_bot. Сайт публикуется через GitHub Pages из корня ветки `main`.

- `index.html` — витрина для покупателей: каталог, корзина, доставка по Казани (улица и дом, встреча у дома), день и время с шагом 15 минут, оплата переводом или наличными, обязательное имя.
- `owner.html` — кабинет владельца. На GitHub Pages сервера нет, поэтому правки в кабинете сохраняются только в браузере того, кто их сделал. Цены и наличие для всех покупателей меняются в `shop.js` (массив `priceList`).
- Заказ уходит сообщением в Telegram владельцу @MayyaSabi. Поддержка — @Dasad_a.
